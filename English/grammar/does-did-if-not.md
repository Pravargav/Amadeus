


## "If he doesn't agree" vs. "If he didn't agree"

### 1. If he doesn't agree
**Use this for a present or future possibility.**

Examples:
- If he doesn't agree, we'll discuss it again.
- If he doesn't agree, we'll look for another solution.
- If he doesn't agree, we won't proceed with the plan.

---

### 2. If he didn't agree
**Use this for a hypothetical or unreal situation (Second Conditional).**

Examples:
- If he didn't agree, what would you do?
- If he didn't agree, we would have to find someone else.
- If he didn't agree, I'd try to persuade him.

---

### 3. Past situation

To talk about an unreal past situation, use **"If he hadn't agreed..."** (Third Conditional).

Examples:
- If he hadn't agreed, we would have postponed the meeting.
- If he hadn't agreed, the project wouldn't have started.

---
