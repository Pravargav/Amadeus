## Conditionals using timelines + tenses

Let's use the same situation:

> He agrees / doesn't agree

---

## 1. Present → Present: Zero Conditional

### Structure

> If + Present Simple → Present Simple

### Example

> If he doesn't agree, we discuss it again.

### Tenses

- doesn't agree → Present Simple
- discuss → Present Simple

### Meaning

This describes a general rule, fact, or normal procedure.

For example:

> If a customer doesn't agree, we discuss the issue again.

It doesn't necessarily refer to one particular customer or one particular occasion.

---

## 2. Present → Future: First Conditional

Now suppose you're talking about a specific situation that may happen.

### Structure

> If + Present Simple → will + V1

### Example

> If he doesn't agree, we will discuss it again.

### Tenses

| Part | Tense |
|---|---|
| If he doesn't agree | Present Simple |
| we will discuss | Future with will |

### Why is "doesn't agree" present tense if we're talking about the future?

Because English normally uses Present Simple after "if" to express a future condition.

❌ If he will not agree, we'll discuss it again.  
✅ If he doesn't agree, we'll discuss it again.

The main clause carries the future meaning:

> If he doesn't agree → we will discuss

---

## 3. Future possibility: First Conditional

The future event is real and possible.

Examples:

> If it rains, we will stay home.

> If I finish early, I will call you.

> If she comes, we will talk to her.

> If he doesn't agree, we will find another solution.

---

## 4. Present/Future hypothetical → Second Conditional

Now change:

> doesn't → didn't  
> will → would

### Structure

> If + Past Simple → would + V1

### Example

> If he didn't agree, we would find another solution.

### Tenses

| Part | Tense |
|---|---|
| If he didn't agree | Past Simple |
| we would find | would + base verb |

### But here's the important part:

Past Simple doesn't necessarily mean past time here.

Compare:

> If he didn't agree, we would find another solution.

This can refer to a hypothetical present or future situation.

You're basically saying:

> "Imagine that he doesn't agree. What would we do?"

---

## 5. Present vs hypothetical future

Compare these carefully:

### First Conditional

> If he doesn't agree, we will find another solution.

This is a real possibility.

### Second Conditional

> If he didn't agree, we would find another solution.

This is hypothetical.

The difference isn't simply "present vs future."

It's mainly:

**First conditional = realistic possibility**

**Second conditional = hypothetical/unlikely/distant possibility**

---

## 6. Past → Past: Third Conditional

Now we're talking about something that has already happened.

Suppose:

> He agreed yesterday.

The decision is finished. We can't change it.

But we can imagine a different past.

Now imagine:

> If he hadn't agreed, the project wouldn't have started.

### Structure

> If + Past Perfect → would have + V3

### Example

> If he hadn't agreed, the project wouldn't have started.

### Tenses

| Part | Tense |
|---|---|
| he hadn't agreed | Past Perfect |
| project wouldn't have started | would + have + V3 |

---

## 7. Why "hadn't agreed"?

Because we're going further back into the past.

Suppose:

Monday: He agreed.  
Tuesday: Project started.  
Today: We're talking about it.

To imagine changing Monday:

> If he hadn't agreed, the project wouldn't have started.

We use Past Perfect because we're talking about an unreal condition in the past.

---

## 8. All four conditionals

### Zero Conditional

**Present → Present**

> If he doesn't agree, we discuss it again.

> If + Present Simple → Present Simple

---

### First Conditional

**Present → Future**

> If he doesn't agree, we will discuss it.

> If + Present Simple → will + V1

---

### Second Conditional

**Past Simple → would + V1**

> If he didn't agree, we would discuss it.

But the meaning can be present/future.

---

### Third Conditional

**Past Perfect → would have + V3**

> If he hadn't agreed, we would have changed the plan.

---

## 9. The tense progression

This is the most useful pattern to remember:

| Conditional | If-clause | Result clause | Time/meaning |
|---|---|---|---|
| Zero | Present Simple | Present Simple | General fact/rule |
| First | Present Simple | will + V1 | Real possible future |
| Second | Past Simple | would + V1 | Hypothetical present/future |
| Third | Past Perfect | would have + V3 | Unreal past |

Using your exact example:

### Zero:

> If he doesn't agree, we discuss it again.

### First:

> If he doesn't agree, we will discuss it again.

### Second:

> If he didn't agree, we would discuss it again.

### Third:

> If he hadn't agreed, we would have discussed it again.

---

## 10. A simple way to think about the tense

Think of it as three levels of distance:

### 🟢 Real / possible

> If he doesn't agree, we'll find another solution.

Present tense in if-clause → future result

---

### 🟡 Imaginary / hypothetical

> If he didn't agree, we'd find another solution.

Past tense in if-clause → hypothetical present/future result

The past tense here creates distance from reality, not necessarily past time.

---

### 🔴 Impossible to change because it is past

> If he hadn't agreed, we would have found another solution.

Past Perfect → imaginary alternative past

---

## One rule worth memorising

**REAL GENERAL:**

> If + present → present

**REAL FUTURE:**

> If + present → will + V1

**HYPOTHETICAL:**

> If + past → would + V1

**UNREAL PAST:**

> If + had + V3 → would have + V3

So when you see **didn't**, don't automatically think past time.

> If he didn't agree, what would you do?

can be about tomorrow.

But:

> If he hadn't agreed, what would you have done?

is definitely about a past situation that didn't happen.
