
#### Tip : Infinitive and Helping Verbs

When you use **"to"** as part of an infinitive verb form, it is always followed by the base form of the verb *(V1)*.



#### Note2 : usage of is/was/do/did

- **IS / WAS** → used with *adjectives*, *nouns*
  
- **DO / DID** → used with *base verb (V1)*






#### do / does / did Questions (Simple Tenses)

**Note** : *Do / Does/ Did always succeded by v1 so used only in simple present/past type questions.*

🔸 Present Simple: Do/Does → is / are, Main verb → V3
🔸 Past Simple: Did → was / were

##### Examples #####
Active:
-> Does he write a letter?

Passive:
-> Is a letter written by him?
