


# Interrogative Sentences: Active Voice → Passive Voice

## 1️⃣ Do / Does / Did Questions (Simple Tenses)

### Rule

**Active:**
```
Do/Does/Did + Subject + V1 + Object?
```

**Passive:**
```
Is/Are/Was/Were + Object + V3 + by + Subject?
```

### Examples

✅ **Active:** Do you play cricket?  
➡ **Passive:** Is cricket played by you?

✅ **Active:** Does she write letters?  
➡ **Passive:** Are letters written by her?

✅ **Active:** Did they complete the project?  
➡ **Passive:** Was the project completed by them?

---

## 2️⃣ Is / Am / Are / Was / Were Questions (Continuous Tenses)

### Rule

**Active:**
```
Is/Am/Are/Was/Were + Subject + V-ing + Object?
```

**Passive:**
```
Is/Am/Are/Was/Were + Object + being + V3 + by + Subject?
```

### Examples

✅ **Active:** Is she cleaning the room?  
➡ **Passive:** Is the room being cleaned by her?

✅ **Active:** Are they watching a movie?  
➡ **Passive:** Is a movie being watched by them?

✅ **Active:** Was he repairing the car?  
➡ **Passive:** Was the car being repaired by him?

✅ **Active:** Were the workers building the bridge?  
➡ **Passive:** Was the bridge being built by the workers?

---

## 3️⃣ Has / Have / Had Questions (Perfect Tenses)

### Rule

**Active:**
```
Has/Have/Had + Subject + V3 + Object?
```

**Passive:**
```
Has/Have/Had + Object + been + V3 + by + Subject?
```

### Examples

✅ **Active:** Has she finished the work?  
➡ **Passive:** Has the work been finished by her?

✅ **Active:** Have they sent the invitations?  
➡ **Passive:** Have the invitations been sent by them?

✅ **Active:** Had he written the report?  
➡ **Passive:** Had the report been written by him?

---

## 4️⃣ Questions Starting with Modal Verbs

### Rule

**Active:**
```
Modal Verb + Subject + V1 + Object?
```

**Passive:**
```
Modal Verb + Object + be + V3 + by + Subject?
```

### Examples

✅ **Active:** Can you solve this problem?  
➡ **Passive:** Can this problem be solved by you?

✅ **Active:** Will she complete the task?  
➡ **Passive:** Will the task be completed by her?

✅ **Active:** Should they follow the rules?  
➡ **Passive:** Should the rules be followed by them?

✅ **Active:** Must we obey the law?  
➡ **Passive:** Must the law be obeyed by us?

---

# Quick Summary

### Simple Tenses

```
Do + V1      → Is/Are + V3
Does + V1    → Is/Are + V3
Did + V1     → Was/Were + V3
```

### Continuous Tenses

```
Is/Am/Are + V-ing
→ Is/Am/Are + being + V3

Was/Were + V-ing
→ Was/Were + being + V3
```

### Perfect Tenses

```
Has/Have/Had + V3
→ Has/Have/Had + been + V3
```

### Modal Verbs

```
Modal + V1
→ Modal + be + V3
```
