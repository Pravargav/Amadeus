# Future Tenses - Formulas

## 1️⃣ Simple Future Tense

### Formula

**Affirmative**
```
Subject + will + V1 + Object
```

**Negative**
```
Subject + will not + V1 + Object
```

**Interrogative**
```
Will + Subject + V1 + Object?
```

### Examples

✅ She will write a letter.

✅ She will not write a letter.

✅ Will she write a letter?

## 4️⃣ Future Perfect Continuous Tense

### Formula

**Affirmative**
```
Subject + will have been + V-ing + Object + since/for + time
```

**Negative**
```
Subject + will not have been + V-ing + Object + since/for + time
```

**Interrogative**
```
Will + Subject + have been + V-ing + Object + since/for + time?
```

### Examples

✅ She will have been writing a letter for two hours.

✅ She will not have been writing a letter for two hours.

✅ Will she have been writing a letter for two hours?

# Quick Summary

## Future Tense Formulas

```
Simple Future
S + will + V1 + O

Future Continuous
S + will be + V-ing + O

Future Perfect
S + will have + V3 + O

Future Perfect Continuous
S + will have been + V-ing + O + since/for + time
```
## Note: 

Simple future -> will + Simple present 

Future continuous -> will + present continuous(i.e. be + v4ing)

Future perfect -> will + present perfect

Future perfect continuous -> will + present perfect continuous
