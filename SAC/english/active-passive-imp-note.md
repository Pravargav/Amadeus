
### 🔹 Key Rule (MOST IMPORTANT)

👉 Active interrogative sentences that start with Do / Does / Did

👉 Passive interrogative sentences start with Is / Are / Was / Were

### ✅ Correct Rule (REMEMBER THIS)

👉 Active voice NEVER starts with Is / Are / Was / Were to form a question.

👉 Passive voice NEVER starts with Do / Does / Did.
