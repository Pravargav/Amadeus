DDIC stands for Data Dictionary in SAP.

What is DDIC?

The SAP Data Dictionary (DDIC) is a central repository that stores definitions of database-related objects used across the SAP system. It ensures data consistency and reusability.

-> Common DDIC Objects

Tables: Store application data.

Data Elements: Define the meaning and description of a field.

Domains: Define the technical attributes of a field (data type, length, value range).

Search Helps: Provide F4 value help.

Structures: Group related fields without storing data.

Views: Logical views of one or more tables.

Lock Objects: Manage data locking.
